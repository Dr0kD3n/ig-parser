## Priority Issues

### [P0] Keyboard/accessibility baseline is broken

Global `outline: none` hides focus; some role-buttons lack Enter/Space activation; key targets are below 44 px. Remove outline suppression, add shared `:focus-visible`, use semantic buttons, enlarge hit areas, add explicit names, and support reduced motion. `40:46:src/styles/base.css`, `376:400:src/styles/components.css`, `1217:1227:src/components/ScheduleTab.jsx`

Suggested command: `$impeccable audit`

### [P1] Daily task does not drive information architecture

Five top modules and nine settings sections expose system structure. No daily queue, next action, blocker, or outcome. Reorganize around Today, Collection, Contacts, Outreach, Analytics; consolidate settings; add a daily summary. `32:38:src/constants/settings.js`, `11:31:src/components/SettingsTab.jsx`, `427:476:src/components/StatisticsTab.jsx`

### [P1] High-impact bulk commands look equally safe
